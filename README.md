# 教育費貯蓄プランナー

進路（公立中→公立/私立高→大学）と費用項目・金額を選ぶと、支払い時期ごとの費用と必要な月額積立を計算する静的Webアプリです。
計算はすべてブラウザ内で行い、入力はサーバーに送信しません（localStorage に保存）。

## 起動（Docker）

```sh
docker compose up -d --build
# http://localhost:8080
```

`docker build -t education-planner . && docker run -p 8080:8080 education-planner` でも起動できます。

## 開発

```sh
npm start   # http://localhost:8080 （python の簡易サーバー）
npm test    # 計算ロジックのテスト（Node 18+）
```

## 構成

- `public/js/calc.js` — 計算ロジック（月次タイムラインと、残高が尽きない最小の月額積立の算出）
- `public/js/presets.js` — 資料に基づく費用の初期値と入学時一時金の仮置き
- `public/js/app.js` — フォーム・結果表示

## 計算モデル

各段階（中学・高校・大学）の総額から入学時一時金（4月）を引いた残りを在学月数で均等割りします。
月初に積立し、家計から毎月出せる額を超えた分を貯蓄から支払うとして、`現在の貯蓄 + 積立×経過月数 − 貯蓄からの累計支出 ≥ 0` を全月で満たす最小の月額を求めます。
金額は概算で、奨学金・就学援助・運用益・物価上昇は含みません。
